# 妙手神透 (MSST)

融合传统五行八卦与现代算法的智能彩票号码生成器。

## 📖 简介

**妙手神透**是一款支持双色球和大乐透的智能彩票号码生成工具。通过红佛女（选红球）、蓝若寺（选蓝球）自定义号码，融合生日、星座、生辰八字等传统命理元素，结合历史开奖数据的智能杀号规则，生成兼具个人印记与统计分析的彩票号码。

✨ **核心亮点**：

- 双色球 / 大乐透双玩法切换
- 28 条专业杀号规则 + 14 条选号规则 + 11 条定胆规则
- 7 种过滤规则智能校验组合质量
- 5 套矩阵缩水公式降低投入成本
- 红佛女 / 蓝若寺手动选号，加权池提升"心仪号码"命中率
- 八卦旋转动画 + 票据风格结果展示
- 短链接分享：好友查看原号码并可重新生成
- 移动端 Tab 弹窗交互，PC 响应式两栏布局

## 🎯 号码规则

### 双色球（SSQ）

| 项目 | 规则 |
|------|------|
| 红球 | 1-33，每注选 6 个 |
| 蓝球 | 1-16，每注选 1 个 |
| 单式 | 6 红 + 1 蓝 |
| 复式 | 红球 ≥7 或 蓝球 ≥2，系统自动组合 |
| 胆拖 | 胆码（必选）+ 拖码（可选）自动配对 |

### 大乐透（DLT）

| 项目 | 规则 |
|------|------|
| 前区 | 1-35，每注选 5 个 |
| 后区 | 1-12，每注选 2 个 |
| 单式 | 5 前 + 2 后 |
| 复式 | 前区 ≥6 或 后区 ≥3，系统自动组合 |
| 胆拖 | 胆码（必选）+ 拖码（可选）自动配对 |

### 模式自动判断

| 红球/前区 | 蓝球/后区 | 生成模式 | 说明 |
|-----------|-----------|----------|------|
| 0 | 0 | 单式 | 全随机生成 |
| 1-5 | 0 | 单式/复式/胆拖 | 根据用户选择的模式决定 |
| ≥6 | 0 | 复式（强制） | 超出单式上限自动升级 |
| 0 | ≥2 | 复式（强制） | 蓝球超出单式上限自动升级 |
| 已选红+已选蓝 | — | 智能判断 | 按实际数量确定模式 |

## 🔬 规则引擎架构

项目采用流水线式规则引擎，数据逐阶段经过五道处理：

```
历史开奖 → [杀号 28 条] → 候选池 → [选号 14 条] → 定胆 11 条
       → [过滤 7 条校验组合] → [矩阵 5 套缩水公式] → 最终号码
```

### 规则总览

**杀号规则**（排除不看好号码）— 28 条

| 类别 | 规则名称 |
|------|----------|
| 差值杀号 | 减法杀号、龙头杀号、凤尾杀号、首尾差值取尾、红蓝联动绝对值杀 |
| 尾数杀号 | 过热尾数杀、和值尾数杀、和值头尾相加杀、尾数对码杀 |
| 区间杀号 | 断区杀号、区间遗漏杀号、空行空列整区杀 |
| 组合杀号 | 012路杀号、连号邻号排除、重号过热绝杀、极冷深号绝杀、斜连杀号 |
| 多维杀号 | 九维交叉杀号、6 点交叉验证杀号、四重杀红法、奇异数杀号 |

**选号规则**（生成候选号码池）— 14 条

横标纵标法、质合螺旋选号、三点合围、奖号时钟、万能 13 码、双子星组合、黄金分割、五步公式、九宫选号等

**定胆规则**（锁定高置信度号码）— 11 条

和值对半取胆、跨度均值定胆、尾和取位定胆、奇偶差乘定胆、首尾折半定胆、对称对码定胆、邻号顺延定胆、黄金比例定胆等

**过滤规则**（校验组合质量）— 7 条

| 规则 | 校验标准 |
|------|----------|
| 奇偶比 | 保留 3:3、2:4、4:2，拒绝极端比例 |
| 大小比 | 保留均衡分布 |
| 区间分布 | 三区分布合理，单区不超过 5 个 |
| 连号 | 最多 1 组连号 |
| 尾数 | 至少 3 个不同尾数 |
| 和值范围 | SSQ: 80-120, DLT: 70-130 |
| 质合比 | 保留 2:4、3:3、4:2 |

**矩阵规则**（缩水降低投入）— 5 套

旋转矩阵通用、8 码中 4 保 3、7 码中 4 保 3、9 码中 5 保 4、螺旋素数矩阵

### 引擎执行流程

1. **Kill Phase**：所有启用的杀号规则逐一执行，合并排除集合
2. **Select Phase**：首个选号规则产生候选池，剔除已杀号码
3. **Bold Phase**：11 条定胆规则独立输出，交叉验证（≥2 条共同推荐 = 定胆）
4. **Filter Phase**：生成组合并通过所有过滤规则校验
5. **Matrix Phase**：对候选池应用矩阵缩水公式

## 🎨 算法体系

### 1. 运势增强算法

结合天干地支、星座、五行、时辰生成综合种子值：

```
种子 = (天干地支年数值 × 100 + 星座幸运数 × 10 + 五行数值 + 八卦偏移 + 时辰 × 3) % 1000
```

生成号码时 20% 概率优先使用运势幸运数字。

### 2. 加权池算法

合并生日拆解、星座映射、自定义幸运数，每个号码权重 = 出现次数，多来源共同推荐的号码优先选中。

### 3. 智能合并策略

- 用户固定选中的号码始终保留
- 加权池非重复号码 60% 命中率补充
- 不足目标数量则从剩余池中随机补足

### 4. 期号计算

根据开奖日动态推算下一期期号，21:00 前显示当期，21:00 后自动 +1。
